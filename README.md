# The Last Jailer

A choice-driven fantasy RPG for Android.

## Vision

- 5–10 hour story-driven campaign
- Pre-written male disgraced-knight protagonist
- Meaningful branching choices and consequences
- RPG stats, inventory and relationships
- Checkpoints and multiple save slots
- Trophies for discovering important paths/endings
- 12+ fantasy adventure tone

## Development

This repository is the clean project for **The Last Jailer**. The existing PlantRescue project is separate and will not be modified.

### First milestone

Build a playable Chapter 1 vertical slice with the story/choice engine, persistence, basic RPG state, and achievement framework in place so later chapters can be added as content rather than rewrites.
